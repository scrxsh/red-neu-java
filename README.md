# 🧠 Red Neuronal en Java con Deeplearning4j (Maven)

Este proyecto implementa una red neuronal simple utilizando **Java** y la librería **Deeplearning4j**, para realizar tareas como clasificación o predicción.

## 📦 Tecnologías utilizadas

- Java 17+
- [Deeplearning4j](https://deeplearning4j.konduit.ai/)
- ND4J (librería de álgebra lineal)
- Maven (gestor de dependencias)
- Postman
